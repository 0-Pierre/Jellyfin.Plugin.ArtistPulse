# 🔐 Security policy

## Supported versions

Only the latest Artist Pulse release is supported.

## Reporting a vulnerability

Please do not post security-sensitive reports publicly. Use GitHub's private security-advisory reporting for this repository, or contact the repository owner privately with:

- affected Artist Pulse and Jellyfin versions;
- clear reproduction steps;
- impact assessment;
- any suggested mitigation.

Do not include Jellyfin credentials, API tokens, or private server addresses in public reports.
